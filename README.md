## 📌 Project Overview

In this project, the focus was on cracking password using tools in Kali Linux **through the lab in VirtualBox.**

The main purpose is to show how passwords can be cracked using tools in this case John the ripper (JTR) this preinstalled in Kali Linux and as well as online tools provided by Networkwalks for educational purposes only.

---

## 🎯 Objectives

The main objectives of this project are to:

Crack passwords of 3 different pdf documents that are password protected using john the ripper and networkwalks passwords cracking tool and hash tool 

⚙️Tool   

 1.  **John The Ripper**

    
In order to crack the password using JTR,the hash for the password protected needs to be know or generated. This is what will be used to crack the password. The following command was entered in the Linux terminal as shown on the screen shots to determine the hash and store it in a 'txt' file that would be used to crack the password;

    
   **' $ pdf2john "My Locked PDF1.pdf" > Hash.txt '**  then followed by **' $ john hash.txt '** to crack the password from the hash contained in the txt  ' **Hash.txt** ' file. The cracked password is highlighted in orange "**good-luck**"

## 💡 Key Takeaways

- The exercise showed that it very important to have strong security measures put in place.
   
- Strong passwords should be implemented by organizations and users in general especially those handling critical information or data.

- Passwords should at least contain more that 8 characters, alphanumeric and changed periodically for example every 3 months
  
- Stronger passwords make it harder for hackers to easily hack in as this takes longer than for simpler and short passwords made up of words or numbers only
  
- The tools used can be used to assess password strengths during security testing or pen testing an organization's systems.
